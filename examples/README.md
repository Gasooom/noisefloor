# Examples

All data here is **synthetic**, generated by [`generate.py`](generate.py) with a
fixed seed, so the ground truth is known exactly. Model names in
`leaderboard.csv` are fictional.

| File | What it shows |
|---|---|
| `data/rag_baseline.jsonl`, `data/rag_candidate.jsonl` | 600 retrieval-QA questions over 120 documents. The candidate is truly +1.4pp better but *observes* +4.2pp; noisefloor correctly calls it inconclusive. |
| `data/rag_candidate_k5.jsonl` | The candidate sampled 5× per question, for the variance decomposition ("more questions or more samples?"). |
| `data/suite/{main,pr}/` | 14 benchmarks: one real +10pp gain, one real −8pp regression, 12 unchanged. Two of the unchanged ones look significant before correction. |
| `data/leaderboard.csv` | Six fictional models on a 198-question benchmark: the top four are statistically tied. |
| [`validate.py`](validate.py) | Monte Carlo checks of coverage, false-alarm rate, power, and family-wise error. |

```bash
noisefloor compare data/rag_baseline.jsonl data/rag_candidate.jsonl --bootstrap
noisefloor summary data/rag_candidate_k5.jsonl
noisefloor suite data/suite/main data/suite/pr --correction bh
noisefloor leaderboard --summary data/leaderboard.csv
python validate.py --sims 4000
```
